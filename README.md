# 校园AI营养师 · MVP 原型

> 针对大学生的营养辅助工具：适配食堂、生活费、大学生作息，输入身体情况与菜品，AI 快速算出食堂菜的大致营养，标出隐形高油高盐的坑，直接生成「食堂 + 便利店」就能实现的吃饭方案。

## 快速开始

**无需任何安装/构建/联网**，双击 `index.html` 即可打开（推荐 Chrome / Edge / 微信内置浏览器）。

演示建议路径：

1. **个人设置** → 点「载入示例档案」（或手动填好建档），保存
2. **今日点餐** → 搜索「地三鲜」「糖醋里脊」这类菜，看 AI 标出的「伪健康菜 / 高油 / 高盐」坑；再选几道健康菜组成托盘，看热量、蛋白、花费是否超预算
3. **生成方案** → 一键生成一日三餐（食堂 + 便利店补位），看每餐构成与营养达标度
4. **每日上报** → 勾选「熬夜 / 压力大」等状态并提交，得到调整建议；回到「生成方案」重新生成，方案会根据当日状态变化
5. **我的记录** → 查看连续记录天数、上报历史与方案存档、正向鼓励话术

## 项目结构

```
校园AI营养师/
├── index.html          # 单页外壳 + 5 个视图（今日点餐/生成方案/每日上报/我的记录/个人设置）
├── css/style.css       # 移动优先样式
├── js/
│   ├── data.js         # 菜品库（26 道内置菜）、便利店商品、诉求/忌口/状态规则
│   ├── engine.js       # 规则引擎：营养估算、坑检测、方案生成、动态调整（纯函数）
│   ├── storage.js      # localStorage 读写（档案/菜单/上报/方案/托盘）
│   └── app.js          # 视图切换、表单交互、渲染
└── README.md
```

## 核心能力

| 能力 | 实现方式 |
| --- | --- |
| 营养估算 / 隐形坑检测 | 内置菜品库 + 规则引擎（油炸/高钠/高糖/伪健康菜标记） |
| 个性化方案 | 按诉求（皮肤/肠胃/熬夜恢复/减脂/增肌/控糖）+ 忌口 + 日均餐费预算，生成三餐方案 |
| 动态调整 | 每日上报（熬夜/压力/运动/肠胃不适/感冒）触发方案规则调整 |
| 情绪价值 | 连续记录激励 + 正向鼓励话术，刻意避开身材焦虑措辞 |
| 零试错点餐 | 先在「今日点餐」模拟搭配看营养，再去食堂实点 |

## 数据说明与免责

- 菜品营养（热量/蛋白/脂肪/碳水/钠）为**估算值**，基于烹饪方式与份量参考；同一道菜不同食堂做法差异很大，仅供演示与参考。
- 本项目不构成医疗建议。身体有持续不适请及时就医。

## 真实 AI 接口预留

`js/engine.js` 中以下函数是**替换点**，保持函数签名不变即可接入真实能力：

- `analyzeDish(dish, profile)` → 替换为「拍菜识别 + 大模型营养估算」（输入换成图片 URL / 识别文本）
- `generatePlan(profile, status)` → 替换为 LLM 生成个性化方案（可在提示词里注入菜品库 JSON）
- `extractStatus(text)` / `adjustForStatus(profile, status)` → 替换为 LLM 结合历史记录做动态建议

`index.html` 顶部导航可预留「📷 拍菜」入口（MVP 未实现），对接相机/相册选择即可。

## 迁移微信小程序要点

1. **引擎复用**：`data.js` + `engine.js` 是纯 JS 无 DOM 依赖，可直接原样放进小程序（`module.exports` 兼容 CommonJS）。
2. **存储替换**：`storage.js` 的 localStorage → 小程序 `wx.setStorage` / `wx.getStorage`，签名几乎一一对应。
3. **样式迁移**：`style.css` 为移动优先，可对照改写成 WXSS；组件化后把卡片/按钮等抽成自定义组件。
4. **数据源升级**：MVP 内置菜品库 → 食堂后厨菜谱 + 权威营养成分数据库；拍菜识别用云函数调视觉 API。
5. **后端规划**：登录（微信授权）、云端记录同步、食堂菜单批量导入（运营后台）。
